## 📌 Project Overview

**FreshMart Retail Sales Dashboard** is an interactive Excel-based data analytics project developed to analyze retail sales performance and generate meaningful business insights.

The dashboard provides a comprehensive view of **Sales, Profit, Quantity, Orders, Regions, Categories, Payment Methods, and Store Performance**.

---

## 🎯 Project Objective

The primary objective of this project is to transform FreshMart retail sales data into an interactive dashboard that helps users understand:

* Overall Sales Performance
* Profit Generation
* Quantity Sold
* Order Volume
* Regional Performance
* Category Performance
* Payment Method Usage
* Top Performing Stores
