## 📌 Project Overview

**TrendKart Sales Dashboard** is an interactive Excel-based data analytics project designed to analyze sales performance and identify important business trends.

The dashboard provides a clear view of **Sales, Profit, Quantity, Top Stores, Top Selling Products, and Monthly Sales Performance**.

---

## 🎯 Project Objective

The main objective of this project is to transform TrendKart sales data into an easy-to-understand interactive dashboard that helps analyze:

* Overall Sales Performance
* Profit Generated
* Quantity Sold
* Top Performing Stores
* Best-Selling Products
* Monthly Sales Trends
* Regional and Category Performance
